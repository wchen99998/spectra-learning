# Novogaia visual identity sources

Inspected 18 September 2026: https://www.novogaia.bio/

The HTML snapshot is `novogaia-home.html`. The deck uses the site's CSS foreground `rgb(12,12,12)` and background `rgb(246,247,248)`, PP Neue Montreal sans-serif family, and its existing black vector logomark. Text wordmark is set in the website typeface.

## Logo

Original black SVG: https://framerusercontent.com/images/qn0CrVVtZawm1qC9lphLDJXAr8.svg

Saved unchanged as `assets/novogaia-logo.svg`; converted to vector PDF using:

```sh
rsvg-convert -f pdf -o presentations/assets/novogaia-logo.pdf presentations/assets/novogaia-logo.svg
```

## Original diagrams

All scientific process diagrams are TikZ code in `novogaia_spectra.tex`. The phenol molecule, peak bars, example adjacency matrices and alignment heatmap are schematic; none is presented as a measured molecule/spectrum correspondence. The analytic mode-growth plot is generated by `make_dynamics_figure.py` from the equation supplied in the user's dynamics analysis.

## Publication figure typography

Following the user's Nature-quality requirement, scientific diagram labels use bundled Liberation Sans TrueType fonts (regular, bold, italic and bold italic), an Arial-compatible standard sans-serif. The open-font license is bundled as `assets/LiberationSans-LICENSE.txt`. PP Neue Montreal remains in the presentation's titles and company wordmark. Standalone figure PDFs have native, embedded text and white backgrounds; the dynamics plot also provides live SVG text.
