# Speaker notes

The deck answers the user's specific question about the latest periodic checkpoint and the parent that initializes its teacher. The user's concern about token-level information motivates the primary readouts and sparse dictionaries. Mean pooling is a baseline, not the only representation evaluated.

1. **Conclusion.** Final token-attention MACCS AUROC is 0.7987 parent versus 0.7750 latest. This is measured accessible chemistry under fixed readouts, not a proof about all information in the representation. Improved sparse reconstruction has a different interpretation.
2. **Lineage.** Parent 1,190k initializes the teacher. The periodic student and optimizer start fresh. Student encoder copies occur every 50k updates; the latest checkpoint contains a teacher from 1,200k and student from 1,209k. The two evaluated step numbers belong to different histories.
3. **Panel.** One spectrum per connectivity identity; 4,096/1,024/1,024 train/validation/test. Chemical labels derive from verified structures. Representation and feature hyperparameters are not selected on test. The benchmark has prior repository exposure; within-study separation is not an entirely new external test set.
4. **Readouts.** Same per-token affine-free LayerNorm and classifier, with four attention queries adding 8,192 parameters. CLS is excluded. Both raw block 19 and final-token comparisons favor the parent; attention improves the latest over its mean baseline. Ensemble AUROC uses mean logits.
5. **Geometry.** Rank changes sharply with normalization: raw block 19 favors parent in projected rank, whereas the final state favors latest. Geometry aggregates the full panel; input decoding is evaluated on held-out tokens. Neither rank nor token cosine is a chemical score.
6. **SAE method.** Direct native JAX training with 8,192 features. TopK32 is primary; seed and k64 controls probe stability. Editing uses the original activation minus the selected feature contribution, preserving the reconstruction residual. Matched controls use the same requested amplitude along another decoder direction or an orthogonal random direction.
7. **Reconstruction.** Held-out explained variance is 72.8% parent and 89.1% latest for the primary dictionaries. All six fits hit the 40-epoch budget, so this is a fixed-budget result rather than a convergence comparison. The larger latest test nonfiring fraction is also recorded in the study.
8. **Associations.** Ten candidates per model are frozen: two each amide, hydroxyl, halide, nitrile and sulfonyl. No amine candidate passed. Dense channels and random dictionaries also recover associations; SAEs do not uniformly dominate those baselines.
9. **Stability.** Features are matched using training activations without chemical labels. The latest halide f7363 replicates well; nitrile can replicate while failing chemistry. Feature IDs cannot be compared directly across dictionaries. Two latest hydroxyl candidates map to one replica.
10. **Feature interventions.** Every selected feature is retained. Thirty-eight of forty corrected target-logit contrasts pass Holm. This only establishes influence on frozen chemical decoders. Negative molecules and other chemical outputs also respond; several removals improve target loss. Realized BF16 control norms are approximately matched, with larger discrepancies in some latest amide/hydroxyl controls.
11. **Failure lesson.** Latest nitrile f3348 has test AUROC 0.496 yet affects the nitrile output. Full reconstruction increases all-supported balanced BCE by 0.01145/0.01312, so high explained variance is not task-loss preservation. No positive steering establishes sufficiency.
12. **Halide case.** The figure shows frozen, deterministic post-confirmation examples. Both positive and negative molecules activate the same feature. Molecular SMARTS labels are structural facts; peak highlights are activation locations without validated fragmentation assignments.
13. **Neighbors.** Full-bank nearest-neighbor Morgan similarity declines. Strict nuisance matching changes both the candidate bank and supported query population: 472 test molecules have at least two candidates. The matched contrast includes zero. Do not describe this as universal chemistry destruction.
14. **Components.** Every block branch was screened on validation. Only three selected attention layers per encoder receive individual head tests, giving 24 tested heads rather than all 200. Nonlinear gating and normalization make individual head effects non-additive. Test-best labels are descriptive rankings within the frozen set.
15. **Rescue.** Clean state restoration at corrupted peak slots recovers the original readout vector better than random uncorrupted slots. All-state restoration is exact. Because corruption causes little class-balanced chemical loss damage in this 256-molecule cohort, loss recovery is inconclusive. This is signal-route evidence, not a fragment-specific mechanism.
16. **Peak robustness.** The latest suffers a smaller increase in ordinary BCE after peak removal, but both clean and corrupted absolute error still favor the parent. Input scores use 177 train-active outputs; do not directly compare their loss magnitudes to the supported, class-balanced causal summaries.
17. **Metadata experiment.** A true repeat supplies an observed collision-energy value. Raw block-25 patching crosses old/new upstream conditioning with old/new final conditioning while keeping the physical spectrum fixed. Both self-patch diagonals are exact. All other selected metadata fields match.
18. **Metadata results.** Latest CE sensitivity is larger and includes a positive path interaction. Mean final-only loss change can be near zero while individual predictions move. Repeat cosine is a readout-vector statistic, not token or embedding cosine. An acquisition change is not a molecular counterfactual.
19. **Synthesis.** Keep the endpoints separate. Sparse fidelity and peak-removal robustness improve; token chemistry favors the parent; restricted neighbor differences are inconclusive; CE invariance worsens.
20. **Numerics.** Primary experiments use native JAX BF16, full dynamic traces and batch 8. Exact cached-forward parity was required. Batch 16 and PyTorch exports change the numerical function despite identical weights. Archived initial runs are excluded. Cross-job readout differences are tiny but paired interventions remain within one graph.
21. **Boundaries.** No matched training-recipe control, exhaustive circuit, positive sufficiency, head-feature mediation or measured fragment labels. These are next discriminating experiments, not results of this report. The parent remains the reference for the tested chemistry tasks.
22. **Reproduction.** The report build uses saved compact numbers and existing Python/LaTeX tools. It launches no model jobs. Slide evidence, figure provenance, vector sources and an inspected PDF accompany the report. Method references motivate the tests; they are not evidence for this model's outcomes.
